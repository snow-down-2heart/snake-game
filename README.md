# 🐍 贪吃蛇游戏

一款可直接在浏览器中运行的贪吃蛇游戏，附带多食物奖励系统和手机触屏适配。

## 快速开始

直接打开：https://snow-down-2heart.github.io/snake-game/

或在浏览器中直接打开 index.html。

## 游戏特性

### 🎮 控制方式
- **桌面端**：方向键 / WASD 控制方向，空格暂停
- **手机端**：滑动控制方向 + 虚拟 D-Pad 按钮

### 🏆 奖励系统
| 食物 | 分值 | 行为 |
|------|------|------|
| 普通食物 | +10 | 始终存在，吃完立即刷新 |
| 金豆 ⭐ | +30 | 每12秒出现，持续6秒后消失 |
| 宝石 💎 | +50 | 随机25-45秒出现，持续5秒 |

### 🏅 成就里程碑
30 分 → 小试牛刀 → 60 分 → 渐入佳境 → 100 分 → 破百！→ 200 分 → 蛇王 → 350 分 → 开挂了吗？→ 500 分 → 传说级

### ⚡ 动态难度
每 50 分升级一次，速度递增。

## 技术栈
纯 HTML + CSS + JavaScript，单文件无依赖。
